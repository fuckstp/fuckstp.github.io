# CentOS 7.4 离线安装Zabbix 5.0 LTS

> 不知不觉Zabbix从4.x更新到了5.0的稳定版，界面上有着挺大的变化。我从4.x版本开始接触Zabbix，它在我日常运维上给予了非常大的帮助。新公司由于虚拟化集群不允许访问外网，在部署Zabbix的过程浪费了许多时间，这里记录一下如何用 YUM 命令简单快捷地在离线情况下安装Zabbix。

> 版本说明：这是2020年的实验记录。CentOS Linux 7已于2024年6月30日结束生命周期，Zabbix 5.0也已不在官方支持版本之列。下面的版本选择、仓库和截图按当时环境保留，新部署请重新核对受支持的系统与Zabbix组合。

### 0.3. 关闭SELinux

这次实验为了简化排查，我关闭了SELinux，下面保留当时的操作。安装Zabbix本身不要求关闭SELinux；实际部署应根据日志配置所需策略和布尔开关，不要把关闭它当成固定安装步骤。

```
 vi /etc/sysconfig/selinux
 
将SELINUX=enforcing 修改成disabled，然后重启

# This file controls the state of SELinux on the system.
# SELINUX= can take one of these three values:
#     enforcing - SELinux security policy is enforced.
#     permissive - SELinux prints warnings instead of enforcing.
#     disabled - No SELinux policy is loaded.
SELINUX=disabled
# SELINUXTYPE= can take one of three two values:
#     targeted - Targeted processes are protected,
#     minimum - Modification of targeted policy. Only selected processes are protected.
#     mls - Multi Level Security protection.
SELINUXTYPE=targeted

```

### 2.4. 防火墙放行端口

端口要按角色和连接方向放行：被动检查是server/proxy访问agent的TCP 10050；主动检查是agent访问server/proxy的TCP 10051。这里Web前端用HTTP，所以还需要TCP 80；如果配置HTTPS，则按实际监听端口放行。下面同机安装server、agent和前端，因此列了这三个端口，分开部署时不能照着每台全开。

```
firewall-cmd --permanent --add-port=10050/tcp

firewall-cmd --permanent --add-port=10051/tcp

firewall-cmd --permanent --add-port=80/tcp

firewall-cmd --reload
```

## 3. 在Web界面对zabbix进行安装配置

## 5. 总结

离线安装其实也很简单，主要的问题是如何得到完整的安装包。可以在联网Linux上使用yum的仅下载功能，再用SFTP把文件传到离线机上。需要注意，下载机和安装机的系统版本、架构、仓库版本和已有软件包要尽量一致；下载机已经装好的依赖，未必会再次下载。最好先在同样的干净离线环境里完整安装一遍，确认Zabbix、PHP、数据库等依赖都齐全。`yum localinstall` 仍可能访问启用的在线仓库，离线安装时应禁用这些仓库，使用已经准备好的本地包或本地仓库。

使用方法：

```
只下载：
--downloadonly

指定下载目录：
--downloaddir=/tmp

连起来一起用：
yum install -y zabbix-web-mysql-scl zabbix-apache-conf-scl zabbix-server-mysql zabbix-agent --enablerepo=zabbix-frontend --downloadonly  --downloaddir=/tmp 

```

上面命令只针对列出的Zabbix相关包，并不等于把整套环境都打包好了，数据库等组件还要单独确认。后续离线安装Grafana也可以用这个思路，关键还是依赖齐全，并经过离线验证。

那么，现在你可以在想要监控的设备上配置SNMP功能，或者安装Zabbix-agent客户端，这样你就能在Zabbix上实时监控设备了。
